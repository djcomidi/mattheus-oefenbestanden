# Bach's Mattheus Passie - Koor Oefenbestanden

## Hoe een oefenbestand downloaden

1. Klik op het koor waar je in zingt.

2. Klik op de stemgroep waartoe je behoort.

3. Klik op het oefenbestand dat je wilt downloaden.<br>
(Github maakt melding dat het bestand niet kan worden weergeven, dit is normaal)

4. Klik bovenaan rechts op de knop met de 3 puntjes.

5. In dit menu kun je `Downloaden` / `Opslaan als` selecteren
